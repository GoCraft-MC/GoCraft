# Vanilla item definitions

`vanilla/1.21.4/item_definitions.json` is GoCraft's protocol-neutral source of
static item metadata. The server embeds and decodes it once; gameplay lookups
never read files or access the network.

The base definitions come from the `vanilla/Item List` report generated by the
official Minecraft Java Edition 1.21.4 server jar. The jar is pinned by Mojang's
launcher-manifest SHA-1:

`4707d00eb834b446575d89a61a11b5d548d8c001`

Generate the official input with:

```text
java -DbundlerMainClass=net.minecraft.data.Main -jar server-1.21.4.jar --reports --output <directory>
```

Then regenerate GoCraft's catalogue with:

```text
go run ./internal/cmd/genitemdefinitions \
  -items-report <directory>/reports/items.json \
  -pumpkin-items <pumpkin>/assets/items.json \
  -pumpkin-tags <pumpkin>/assets/tags/26_2_tags.json
```

The generator also consumes the checked-in 1.21.4 item ID, network-tag, and
fuel catalogues. It records SHA-256 hashes for every input in its output.
Where Mojang exposes no matching item tag, the generator adds supplemental
`gocraft:` categories (currently dyes and banner patterns) to the same tag
index; gameplay never infers those categories from item names.

GoCraft currently exposes eleven post-1.21.4 armor items through its newer
Bedrock compatibility data. Those exact IDs are an explicit extension sourced
from Pumpkin's generated components and 26.2 tags at revision
`99989ba3b6a292fcdf36473065e4d365b6f89928`; they are listed in the output's
`_compatibility_extensions` field. The output records hashes of both generated
inputs. No other newer items are mixed into the 1.21.4 base set.
